How to evaluate good engineers in the AI era

🌿 Growingest.further readingStarted 22 Sept 20261 min read#ai#engineering

Inspired by AI is breaking our proxies for expertise

  • Code is cheap now
  • Good manually crafted code is harder to stand out in the flood of AI slop

What was deemed good effort to be rewarded is different

From The Manager’s Path in the Age of AI

if someone wrote code to solve a problem, it was a sign they were really willing to put in some elbow grease and effort, they cared a lot, they had a strong opinion. This didn’t always lead to great outcomes, but it was a useful signal that whoever wrote that code cared. Nowadays? Code is cheap.

Having lots of code on your github used to be a good proxy to show that you're good at coding

But now everyone can generate lots of code.

From AI is breaking our proxies for expertise

It used to be that you could put a meaty project on your GitHub — say, an emulator, or a toy OS — and people would know you were a skilled engineer. But now projects like that are worthless, because everyone just assumes they’re vibe-coded
